# Banyan 🌳

A place where young builders in India get seen — **for what they've shipped, not their credentials.**

Most of the events, funding, and exposure for young builders live in the US. If you're a teenager in India building real things, you can be genuinely good and still invisible — no one looking, no door in. Banyan is a small fix for that: a page that features young Indian builders and what they've made, so the next kid doesn't build alone.

## How it works

One page, one list. Each builder is an entry in a JavaScript array in `index.html` — a name, a line, and links to what they've shipped. Adding a builder is adding one object. No backend, no accounts, no gatekeeping.

## Get on Banyan

Built something real — a tool, an app, a paper, a project? Two ways in:

- Open a pull request adding your entry to the `BUILDERS` array in `index.html`, or
- Use the **Submit your build** link on the page.

The only bar is that you shipped something real. No degree, no connections needed.

## Run it

Open `index.html` — it's one file, no build step. `index.html?check` runs a self-test.
